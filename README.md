# 🐄 Gau Seva (गौ सेवा) — Cow Rescue & Care Network

> **"One report. One helping hand." / "एक सूचना • एक सेवा भाव"**

A modern, responsive web application prototype for citizen reporting, emergency triage, volunteer rescue dispatch, and Gaushala shelter coordination.

---

## ✨ Features

- **🚨 6-Step Citizen Cow Reporting:** Photo upload, problem categorization (Injured, Road Accident, Sick Calf, Trapped), interactive map location pin, urgency selection (Emergency, Urgent, Normal), and instant dispatch.
- **📍 Live Case Tracking:** Real-time vertical timeline (*Report Submitted → Verified → Team Assigned → En Route → On Site → Treatment → Completed*) with emergency vehicle ETA and live status simulator.
- **🗺️ Nearby Cases Interactive Map:** Filterable map & feed with location pins across Jaipur.
- **🦺 Volunteer Experience:** Dedicated responder dashboard, available rescue missions, 1-click stage progression, and Before & After treatment documentation.
- **🛡️ Admin Command Center:** Master triage table, volunteer assignment modal, and analytics overview.
- **💝 Community Support & Donations:** Direct contributions for green fodder, veterinary medical kits, ambulance fuel, and instant demo receipts.
- **🏛️ Gaushala Directory:** Verified local shelters directory with capacity, facilities, and contact helplines.
- **🌐 Bilingual UI:** Full English and हिन्दी support with 1-click toggle.

---

## 🛠️ Tech Stack

- **Framework:** React 19 + Vite 6
- **Icons:** Lucide React
- **Celebration Effects:** Canvas Confetti
- **Styling:** Nature-inspired Design System (Vanilla CSS with Custom Tokens & WCAG AA Contrast)
- **Deployment:** Vercel / Netlify ready

---

## 🚀 How to Run Locally

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the local development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.

4. Build for production:
   ```bash
   npm run build
   ```
